# ☕ BlogCafé - Plataforma Web & Cursos de Café

*BlogCafé es una aplicación web responsiva orientada a la divulgación de consejos sobre café, recetas y venta de cursos de formación profesional.*

## 🚀 Tecnologías
* **Frontend:** HTML5, CSS3 / SASS, JavaScript (ES6+).
* **Backend Base:** PHP.
* **Diseño:** Responsive Design (Mobile First).
